
# Geospatial Data Analysis

## Objective
To analyse location-based sales data and identify
the best areas for business expansion.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Folium

## Analysis Performed
1. Sales analysis by city.
2. Customer demand analysis.
3. Existing store analysis.
4. Business expansion opportunity detection.
5. Geographical map visualization.

## Result
Successfully identified locations with high
customer demand and fewer existing stores.
